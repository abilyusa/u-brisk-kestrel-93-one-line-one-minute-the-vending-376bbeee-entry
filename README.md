One pickup line, as if a vending machine were flirting with a passing human:

> They fill me with snacks and empty my coin box, but nobody ever asks what I want. I want you — and a restock on Friday.

Run `node main.ts`; it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`).
